위드 아카데미 - 메뉴별 개별 페이지 버전

업로드 방법:
1. ZIP 압축을 해제합니다.
2. 안에 들어 있는 HTML 파일 9개를 GitHub 저장소의 메인(main) 브랜치 최상위 폴더에 업로드합니다. 기존 index.html은 덮어씁니다.
3. 기존 이미지 파일(logo.png, profile_*.jpg, p1.jpg 등)과 i.mp4를 삭제하지 마세요. 모든 HTML 파일과 같은 폴더에 있어야 합니다.
4. GitHub에서 Commit changes 후 Settings > Pages 또는 Actions에서 배포가 끝날 때까지 기다립니다.
5. https://www.yth-up.co.kr/ 접속 후 Ctrl+Shift+R로 강력 새로고침합니다.

페이지 구성:
index.html - 메인(메뉴 카드)
about.html - 소개
news.html - 청년 현실
instructors.html - 강사진
curriculum.html - 커리큘럼
gallery.html - 갤러리
history.html - 연혁
reviews.html - 후기
contact.html - 상담 신청

주의: 기존 HTML의 상담 신청 버튼은 실제 서버 전송 없이 알림만 띄우는 데모 동작입니다. 별도의 폼 전송 기능 연결이 필요합니다.
